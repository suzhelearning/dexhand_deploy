# Faithful v131 model-state execution

User approved independent q_ref/qdot/qddot progression; sequential execution,
no subagents, no commits, no hardware runs. This supersedes feedback-derived
history in the previous full-port plan.

only seed initialization after an explicit lifecycle reset. Main FK/Jacobian
uses the original MuJoCo fast model in world coordinates; host Base targets
are transformed at the adapter boundary. Existing robot viewer/hand assets and
other solver defaults remain unchanged. Original fast-model limits apply inside
this backend; host position/transport safety remains an additional check.

The direct smoke exposed a pre-existing return endpoint cancellation:
0.2 + (0.9599310886 - 0.2) != 0.9599310886. Added a failing regression then
changed only the completed interpolation endpoint to exact Home; intermediate
trajectory, velocity and fresh-state/hand return barriers are unchanged.

MuJoCo conda library requires GLIBCXX newer than host GCC 11; linked its matching
conda libstdc++ explicitly. Runtime ldd resolves MuJoCo, qpOASES and libstdc++
inside ik-build. Default environment dependencies and other IK defaults remain.

Scope: this is fidelity for the model-state algorithm under identical inputs,
initial state and model. Host mapping/Home, independent optional postprocessing,
and distributed safety remain host integration seams. No live-device guarantee.
